# 数字营销 / 本地获客服务 — 竞品调研

调研日期：2026-08-05
调研目的：为「只卖交付物、不背效果」的独立品牌站与报价单提供定价基准、话术参考与设计方向
调研方法：公开定价页抓取 + 首屏截图 + 行业定价指南交叉验证

---

## 一、结论先行（五条）

1. **市场按「背不背效果」自然分成两个价格带**，中间几乎没有产品。背效果的月费 $285–2,200，不背效果的工具订阅 $10–70/月。你要做的「一次性诊断报告 $149–299」这个位置，**在 GTA 华人市场基本是空的**。
2. **华人营销公司几乎全部不公开报价**，北美本地服务商则普遍公开。这是最容易做出的差异化动作——公开价格本身就是信任状。
3. **同行普遍不写免责**，但也普遍不敢承诺具体数字，用的是"increase local customers and leads"这类无法证伪的措辞。你走"明确写清不含项"反而更干净，且是销售话术而非弱点。
4. **免费审计（Free Audit）是这个行业的标准获客入口**，四家里有三家在用。这验证了你上一场对话里"免费简版诊断工具"的判断。
5. **视觉风格两极分化**：华人公司走黑底荧光的炫技风，北美本地服务商朴素到近乎没设计。中间地带（克制、专业、信息密度高、价格透明）是空位。

## 三、同行怎么打包与宣传

### 3.1 页面结构（四家高度一致）

Storyteller Media 的顺序几乎是这个行业的模板：

```
1. Hero：服务名 + 一句价值主张
2. 两到三张套餐卡（价格直接露出）
3. "Who Are We?" 团队介绍
4. 服务收益陈述
5. 四步流程（Strategy → Audit → Management → Optimize）
6. 详细套餐对比表
7. FAQ（6 条）
8. 相关服务卡片
9. 页脚 CTA
```

PLAYHEADS（华人公司）的顺序：核心价值主张 → 六大服务 → 团队实力 → 一站式介绍 → 案例 → 四步流程 → 合作伙伴 logo 墙 → 客户评价 → 页脚。

**共同点**：都有「四步流程」区块。这是低信任行业的标配——把不可见的服务过程可视化。**你必须有这一块。**

### 3.2 CTA 用词

| 服务商 | 主 CTA |
|---|---|
| Storyteller Media | **Book a Discovery Call**（页面出现 4+ 次）+ 每档套餐的 Order Now |
| Renew Local | **Start Free Trial**（7 天） |
| Qode Social | Start Now + **Get Your Free Audit** |
| PLAYHEADS | **预约免费咨询** |
| Storyteller 页脚 | **Free Local SEO Audit** |

**读数**：四家里三家用免费审计/试用做入口。没人上来就要钱。**你的免费简版诊断不是创新，是入场券。**

### 3.3 效果话术与免责

- Storyteller Media：`"increase local customers and leads"`、`"turn your profile into a review-collecting revenue generator"`、`"prevent your Profile from being suspended or disabled"` —— 全是**不可证伪的定性表述**，页面上**无任何免责声明**。
- Qode Social：强调"数据驱动确保可衡量的 ROI"，但**不承诺具体指标**。
- M. Lopez：走另一个极端，直接放 **"300–500% ROI"**、**"30 天退款保证"**、**"90 天出结果的 Performance Promise"**。
- PLAYHEADS / Monet：不公开报价，靠信任状堆——12 年经验、300+ 案例、过亿收入、Google/GoDaddy/WeChat logo 墙、"小红书北美官方认证代理"。

**对你的启示**：
- 市面上要么含糊其辞（多数），要么承诺 ROI 数字（少数，风险自负）。
- 你走第三条：**把"不含什么"明确写出来**。这在满屏含糊承诺的环境里是稀缺的诚实信号，而且它同时是法律护栏。
- ⚠️ **你没有 12 年案例和 logo 墙**，所以不能学华人公司那套信任状打法。你的信任状只能是「方法论 + 交付物样本 + 公开价格」——这三样都不需要客户案例。

### 3.4 商业条款细节（值得抄）

- **年付送两个月**（Storyteller）：$285×12 = $3,420，年付 $2,850。锁定现金流的标准做法。
- **6 个月合约或收设置费**（Qode Social）：二选一，给客户台阶。
- **价格不含 HST**（Qode Social）—— 加拿大报价单**必须写这一句**。
- **按门店计价 + 阶梯折扣**（Renew Local）：1 店 $30，21–30 店 $20。多门店客户的标准结构。
- **无合同、月付、可随时取消**（Renew Local）：低价自助产品的必备承诺。

## 四、三个对你特别有价值的发现

### 1. 「差评申诉 $425/条、GBP 恢复 $750/次」是被验证过的一次性高价服务

Renew Local 把这类项目单独定价，说明市场愿意为**单次、明确、有确定交付物的动作**付高价。这跟你「只卖交付物」的模式完全同构。

⚠️ 但注意：上一场对话已确认**差评删不掉，只能回复**。$425 的申诉是针对违反 Google 政策的评价（涉及仇恨言论、垃圾信息、利益冲突等），成功率不保证。若你要做这一项，必须写成**「申诉代办，不保证结果」**。

### 2. 「帮客户找回 GBP 账号所有权」有明确市场价

Renew Local 的 **GBP 验证 $750 / 恢复 $750**，正好对应上一场对话里发现的痛点——华人商家的 GBP 常年握在外包公司或前员工手里。**这是你 onboarding 环节可以独立收费的项目，且有公开价格背书。**

### 3. 报告生成器可以先租不买

My Web Audit **$69.99–199.99/月**、年付带白标域名，已能生成 Google 商户资料审计。你完全可以**先用它跑前 10 个客户验证需求，再决定要不要自己开发**——这跟你上一场"先人工跑 3–5 个客户再自动化"的结论一致。

## 五、视觉风格分析

### 样本 A：Storyteller Media（加拿大本地 SEO）

- 白底、系统无衬线字体、居中大标题、正文左对齐段落堆砌
- 几乎没有设计成分——像一篇加了套餐卡的博客文章
- 品牌色：深蓝 logo + 橙色链接，无统一色彩系统
- 大量留白但不是设计意图，是内容不足
- **优点**：信息直给、价格露出、加载快、不装
- **缺点**：完全不体现"我们懂营销"

### 样本 B：PLAYHEADS（北美华人营销公司）

- 纯黑背景 + 荧光黄强调色 + 全屏几何菱形图案
- 超大英文 logo 字标、中文粗体大标题、左侧固定社交图标条
- 全屏 hero、滚动动效、案例轮播
- **优点**：视觉冲击强、一眼"专业"、符合华人客户对"营销公司"的期待
- **缺点**：内容密度低、不公开报价、首屏加载慢、说服力靠气势不靠信息

### 你应该走的位置

**两者之间，偏 A 的信息密度 + 偏 B 的设计完成度。**

具体主张：

| 维度 | 建议 |
|---|---|
| 底色 | 浅色为主（象牙白/米白），不要纯黑——黑底是华人营销公司的标配，会被归类 |
| 强调色 | 单一克制强调色（深绿或深蓝），不要荧光色 |
| 字体 | 英文用几何或中性无衬线，中文思源黑体/苹方；**标题不要过大**，靠字重和间距拉层次 |
| 关键动作 | **价格直接印在首页**，这是相对所有华人同行的最大差异点 |
| 信任状 | 不堆 logo 墙、不编案例数字。改为：**交付物样本（真实的诊断报告 PDF 预览）+ 方法论说明 + 公开价格** |
| 必备区块 | 四步流程（行业标配）、FAQ、"不含什么"清单（差异化） |
| 主 CTA | 免费简版诊断（行业入场券），次级 CTA 为直接购买 |
