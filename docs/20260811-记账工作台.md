**建立日期**：2026-08-11
**数据目录**：`finance/`（账本、配置、封账文件、生成的工作台页面）
**工具入口**：`npm run ledger -- <命令>`（零依赖，Node 20+）

## 记账规则（不可协商的部分）

1. **只记真实发生的资金往来。** 计划、报价、意向都不入账——那些属于任务台账。
   没有一笔真实收支之前，账本就应该是空的，空着不丢人，伪造才丢人。
2. **当天发生当天记**（做不到就本周期内补记，备注写清实际发生日）。
3. **原币记账。** 美元订阅记 USD，加元收入记 CAD。汇率只用于折算展示
   （`finance/config.json` 的 `fx`），原币金额永远是真相。
4. **封账后的月份不许增删改。** 封账时该月交易的哈希被冻结进 `finance/closes/YYYY-MM.json`，
   改了 `check` 会直接报错。发现历史错账，在**当前月**做红冲（记一笔反向交易，备注说明冲哪笔）。
   这条沿用 T17 月报「数字生成时冻结」的设计——上个月的数字下个月不能变，否则不能当续费和复盘依据。
5. **周期项只能停用（`active: false`），不能删除。** 删了会导致历史自动过账的交易失去出处，`check` 会抓。
6. **工作台页面（`finance/workbench.html`）是生成产物，不许手改。** 改数据，跑 `report`。

## 口径约定

- **MRR** = 启用中的**收入类周期项**折 CAD 合计。客户签约 → 在 `recurring.json` 加一条收入周期项；
  流失 → `active` 改 `false`（不删）。所以 MRR 和付费客户数不用手算，永远是配置的直接结果。
- **burn** = 启用中的**支出类周期项**折 CAD 合计（GoHighLevel、Local Falcon、云服务等）。
- **一次性收支**（$249 诊断报告、域名、律师费）直接 `add`，不进周期项。

## 全自动的部分（每个工作周期怎么用）

```
开工:   npm run ledger -- roll     # 到期的订阅/月费自动过账（幂等，跑多少次都不会重复）
                                   # roll 会顺带跑 check + 重新生成工作台
看账:   npm run ledger -- status   # 终端 5 行看清全局；要细看就开 finance/workbench.html
记账:   npm run ledger -- add --type expense --project shared --category 工具订阅 \
            --amount 97 --currency USD --who GoHighLevel --note "8月订阅"
月初:   npm run ledger -- close 2026-08   # 封上个月。封账前会强制检查该月周期项都已过账
```

每次 `add` / `roll` / `close` 之后工作台自动重新生成，不存在「忘了更新报表」这回事。
Claude 的执行规则：**每次开工先 `roll`，收工前如有资金变动，`status` 的输出要回写进当次提交信息。**

## 硬停止条件（沿用任务台账的规矩）

- `check` 报错且一次没修好 —— ⛔ 不要修第二次，停下来问。账是钱，不是代码，猜错的代价不对称
- 账实不符（账本和银行/信用卡流水对不上）—— 停下来对账，找到差异原因再继续
- 要记一笔来源或金额不确定的账 —— 不记，先问

## 不变量（`check` 守着的东西）

| # | 不变量 | 破了意味着什么 |
|---|---|---|
| 1 | 每笔交易字段合法（日期真实、金额正数、项目/类目/币种在配置内） | 脏数据进账本 |
| 2 | 交易 id 全局唯一 | 重复记账 |
| 3 | 封账月重算哈希 == 封账文件里的哈希，笔数一致 | 历史被篡改，月报/复盘依据作废 |
| 4 | 自动过账 id（`auto-<周期项>-<月>`）能对应回存在的周期项 | 周期项被删，账目失去出处 |
| 5 | 封账前该月所有启用周期项都已过账 | 封了一个少记了订阅费的月份 |

## 文件清单

| 文件 | 是什么 | 谁改 |
|---|---|---|
| `finance/ledger.jsonl` | 账本本体，一行一笔 | 只通过 `add` / `roll` 追加 |
| `finance/config.json` | 币种、汇率、项目、类目、阶段目标 | 人工，改前想清楚 |
| `finance/recurring.json` | 周期性收支（订阅 / 客户月费）| 人工：开通订阅、客户签约/流失时 |
| `finance/closes/YYYY-MM.json` | 封账快照（汇总 + 哈希 + 当时汇率）| 只由 `close` 生成，永不手改 |
| `finance/workbench.html` | 工作台页面，浏览器直接打开 | 只由 `report` 生成 |
| `finance/scripts/ledger.mjs` | 全部逻辑，零依赖 | 代码改动走正常评审 |

**隐私**：`finance/` 已加入 `.dockerignore`，不会进入部署镜像；仓库本身是私有的，账本随 git 版本化——每一笔账的入账时间都有 commit 为证。
