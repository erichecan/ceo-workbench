# seomachine 提炼成 SEO 工具、走月费模式 — 可行性调研

**日期**：2026-08-11
**看板卡**：c-d85059
**结论先行**：**能做，但不该按「独立 SEO SaaS」做。建议改为月费线的加价模块。**

## 一、家底盘点：这件事你已经规划过了

`seomachine/README.md` 里已经有一个**完整的 SaaS 产品定义**，不是一堆脚本：

- 产品定位：「AI 驱动的 SEO 内容 SaaS 平台」，面向内容运营、独立站站长、SEO 从业者、电商卖家
- 六大能力模块：关键词研究 / AI 写作（多模型路由）/ SEO 分析 / 多平台发布（WordPress + Shopify + Webhook）/ 用量管理 / GA4-GSC 集成
- **定价方案已定**：基础 $29（5 篇/日）· 专业 $79（20 篇/日）· 团队 $199（不限）
- 桌面 App 版本已于 2026-06-22 主动放弃，收敛到 SaaS Web 形态

**已经开发完的**：Phase 0（仓库整合、产品文档）+ 12 个 python 脚本的 DataForSEO 封装

**没开发的**：Phase 1 核心引擎、Phase 2 SaaS 后端（认证/Stripe/Redis 用量）、Phase 3 Web 前端、Phase 4 深度研究 —— **四个阶段全部待开发**

> 所以真正的问题不是「能不能做成月费」，而是「值不值得投四个 Phase 的开发量」。

**seomachine 原定价 $29/$79/$199 落在市场中低位，定价本身没问题。**

### ⚠️ 但赛道已经变了 —— 这是本次调研最重要的发现

Surfer 2026 年的产品重心**不在关键词和写作上**，而在 **AI 搜索可见性追踪**：

- Standard $99：追踪 25 个 AI prompt（仅 ChatGPT，每周刷新）
- Pro $182：追踪 50 个 prompt（ChatGPT + Perplexity + Google，每日刷新）
- Peace of Mind $299：追踪 100 个 prompt，全模型
- **甚至单独拆出一个 $158/月 的产品，只卖 AI 搜索可见性分析**

也就是说：**「关键词研究 + AI 写作」这个组合已经被 Koala 的 $9 和 Frase 的 $15 打成地板价**，
头部厂商靠「你的品牌在 ChatGPT/Perplexity 里被提及了吗」这个新问题赚钱。

seomachine 的六大能力模块，全部落在被打成地板价的那一半里。

## 三、CEO 判断：先做加价模块，最快见到客户

⚠️ **重要修正（2026-08-12，用户纠偏）**：初稿以「打不过 Surfer/Frase」为由建议不做，
这个论证方式错了。**我们的客户不是 SEO 从业者，是本地商家——他们没听说过 Surfer，
也不会去对比功能矩阵。** 只要我们的功能恰好满足他的需求，这事就成了。

所以下面的选择**不是「因为竞争不过所以退而求其次」，而是「哪条路最快把功能送到已有客户面前」**。

### 为什么先做加价模块

1. **客户已经在手上。** localrank 的本地商家客户不需要重新获客，
   月报是他们每月本来就会打开的东西——把排名那一页加进去，交付渠道现成。
2. **开发量是「接脚本进月报」，不是四个 Phase。** `seo_bofu_rankings.py` 和
   `seo_competitor_analysis.py` 已经写好了，能立刻变成客户看得见的东西。
3. **独立 SaaS 随时可以在这之上长出来。** 先有付费客户在用，再决定要不要做成产品，
   比先做产品再找客户稳得多。

### 建议的做法：把 DataForSEO 能力变成 localrank 月费套餐的加价项

| 维度 | 独立 SaaS | 月费线加价模块 |
|---|---|---|
| 开发量 | Phase 1-4 全部 | 复用现有 12 个脚本 + 接进 localrank 月报 |
| 客户 | 从零获客 | **localrank 的本地商家客户，已在漏斗里** |
| 竞争对手 | Surfer / Frase / Koala | 本地同行（几乎没有做排名报告的） |
| 定价方式 | $29-199/月 独立收费 | 月费套餐加价 $30-80/月，或按报告单次收费 |
| 与战略的关系 | 开第四条线 | **补强最弱的月费线** |

**具体形态**：本地商家（餐馆、美甲、维修店）每月收到的月报里，
除了现有的评价数据，加一页「你在 Google 地图/搜索里的排名变化 + 三个同行对比 + 本月该做什么」。
这一页的数据来自 `seo_bofu_rankings.py` 和 `seo_competitor_analysis.py`——**脚本已经写好了**。

这条路径的开发量是「把 python 脚本的输出接进已有的月报生成器」，不是四个 Phase。

## 四、客户会喜欢这一页的什么（做的时候按这个做）

商家打开月报看到排名那一页时，让他有反应的不是数据密度，是这三句话：

1. **「你这个月从第 7 名升到第 4 名」**——排名变化，一个数字，不要图表堆砌
2. **「隔壁那三家的情况是这样」**——同行对比。本地商家最在意的永远是隔壁那几家，
   这一条比任何 SEO 指标都能抓住他
3. **「这个月你该做这一件事」**——只给一条行动建议，不给清单。
   他要的是「照着做就行」，不是「学会 SEO」

**技术上我们做的是 DataForSEO 查询 + 对比计算；客户感受到的是「有人在盯着我的生意」。**
后者才是他续费的理由。

## 六、将来做独立 SaaS 的话，最值钱的切口在这里

不是「关键词 + 写作」，而是 **AI 搜索可见性的本地化版本**：

> 「你的店在 ChatGPT / Perplexity 被问到『多伦多最好的 XX 店』时，会被提到吗？」

Surfer 卖的是品牌级的 AI 可见性（$158-299/月），**但没人做本地商家版本**。
而我们同时握着 localrank 的本地商家客户和 DataForSEO 的数据能力——这是唯一一个
我们有结构性优势的切口。现在不做，但值得记下来。
