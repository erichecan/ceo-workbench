## 二、客户就在手上：print-main 的客户画像完全对得上

`print-main` = **suvernire plus，定制商品电商平台**（README 原文：
"custom merchandise e-commerce platform with **design lab**, order management, and admin dashboard"）。

它的客户是**做定制商品生意的商家**。这些商家的处境是：

> **平台有了（你给他建的，还带 design lab），缺的是往里填的东西。**

一个定制商家要持续卖货，就要持续上新；要持续上新，就要持续有设计。
设计要么自己画（慢）、要么雇设计师（贵）、要么买素材站（人人都有同款）。

**veerytee 补的正好是这一格。** 这是「已有客户 + 已有关系 + 已交付平台」上的加卖，获客成本为零——
这是所有销售里最容易成的一种。

## 三、定价的天花板与地板（2026-08 实测）

| 层级 | 服务 | 价格 | 性质 |
|---|---|---|---|
| **天花板** | Kimp | $699/月起（促销后 $1,397） | 人工设计团队，无限请求 |
| | Design Pickle | $486.75 – $1,949/月 | 人工，行业标杆 |
| | ManyPixels | $439/月起 | 人工，专属设计师，1-2 工作日交付 |
| **地板** | Creative Fabrica | **$9/月**（年付 $4.99） | 素材库订阅，**含完整 POD 商用授权、无限下载** |
| | Printify Premium | $39/月 | POD 平台会员（不是设计服务） |

### 这张表怎么用：它是我们的定价空间，不是威胁

⚠️ **重要修正（2026-08-12，用户纠偏）**：本节初稿把 Creative Fabrica 的 $9 当成「生死线」，
判断错了。**前提就不成立——一个开定制店的商家不逛设计素材站。**
他的对比对象不是 $9 的素材库，是「现在根本没人帮我做这件事」。

**这门生意的本质是信息差套利，而且是合法且有价值的那一种**：我们承担了「知道该用什么工具、
怎么把它跑起来」的认知成本，客户买的是结果。客户不是计算机高手，也不关心 Surfer 或
Creative Fabrica 存不存在——**只要功能恰好满足他的需求，这事就成了。**

所以这张表的正确用法是：**天花板（$439-1,400 的人工设计订阅）证明了这个需求值这么多钱**，
而我们的成本结构让我们能在这个价位下方任意定价。地板价只是背景噪音。

我们交付的东西里，有三样是客户真正会喜欢的：

1. **独占**——这批设计只给他一家，合同写死
2. **选题**——基于他的品类和当下热点选的，不是从百万素材里自己翻
3. **上架完成态**——print_ready + 模特图 + 平铺图 + 社媒素材一整套，**直接能用，不用再加工**

素材站给你一张图，你还要自己做 mockup、自己想文案、自己上架。
**veerytee 给的是「这周你的店该上的 20 个新品，已经做好了」。** 这不是图的生意，是运营的生意。

## 四、三档产品化方案（回答「做到什么程度」）

成本按每个设计出 6 类图算：**6 × $0.042 ≈ $0.25/设计**。

| | **A 档：设计供给** | **B 档：上新托管** ⭐推荐 | **C 档：内容代运营** |
|---|---|---|---|
| 交付物 | 每月 30 个独占设计，6 类图全套 | A 档 + 直接上架到他的店 + 每月上新排期 | B 档 + 社媒素材包 + 热点选题报告 + 数据反馈 |
| 客户还要做什么 | 自己上架、自己做营销 | 只需审核通过 | 几乎什么都不用做 |
| API 成本 | ~$7.6/月 | ~$15/月（60 设计） | ~$25/月（100 设计） |
| 需要的开发量 | **几乎为零**，现有 pipeline 直接跑 | 中：对接客户店铺上架接口（print-main 有 design lab，接口可复用） | 大：选题自动化 + 社媒素材 + 数据回流 |
| 建议定价 | **$99-149/月** | **$249-399/月** | **$499-699/月** |
| 毛利率 | >92% | >94% | >95% |
| 风险 | **高**——最容易被拿去和 $9 素材站比价 | 低——卖的是省下的人力，不是图 | 中——交付面大，做不好容易翻车 |

### 为什么推荐 B 档

- A 档虽然开发量最小，但**它是在卖图**，必然掉进 $9 的比价陷阱
- C 档的价值最高，但交付面太大，第一单就做全栈容易砸口碑
- **B 档卖的是「你不用管上新这件事了」**——客户对比的不再是素材站，
  而是「雇一个兼职运营 vs 每月 $299」，这个对比我们赢面很大
- 而且 B 档的开发量集中在「对接上架接口」，print-main 是你自己建的平台，**接口你最熟**

### 成本结构揭示的一个事实

API 成本只占定价的 **3-5%**。**这门生意的成本不是算力，是审核和沟通的人时。**
所以定价不该按成本加成来定，该按「替客户省下多少人力」来定：
一个兼职上新运营在多伦多至少 $1,500/月，我们卖 $299 是他的五分之一。

## 五、向 print-main 客户提案的切入方式

**不要做成「我有个新产品要卖你」，要做成「我发现你的平台有个空转的地方」。**

1. **先看数据**：print-main 后台能看到客户店铺的上新频率。找出**最近 30 天上新少于 5 个**的商家——
   他们的平台在空转，这就是提案的事实依据，不是推销话术
2. **先给样品，不给报价**：用 veerytee 的 pipeline，针对该商家的品类现出 5-10 个设计，
   连模特图一起发过去。**这和「咨询式 demo」是同一个打法**——不卖服务，先证明我懂你的生意
3. **报价锚定人力**：「一个上新运营 $1,500/月，这个是 $299/月，而且不休假」
4. **第一单可以试点价**：首月 $99 试跑，做出数据（上新数、曝光、成交）再转正价。
   有了第一个案例，后面的商家是拿案例去谈，不是拿 PPT 去谈

## 六、交付要点（让客户满意的三件事）

1. **独占性做成卖点。** 「这批设计只给你一家，同城同品类我不签第二家」——
   这句话本身就是客户喜欢的东西，比任何功能描述都有力。实现方式是按品类划分客户，
   写进合同即可。**它是销售武器，不是技术难题。**
2. **商标检索做成服务的一部分。** 热梗文案可能撞商标，我们顺手过一遍检索再交付——
   **客户自己做不到这件事，而这正是他会说「幸好交给你们」的地方。**
3. **第一批人工过目。** `review_designs.ts` 负责初筛，第一批交付前我亲自看一遍。
   第一印象决定这单能不能续，这个人时值得花。
